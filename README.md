                    Описание проекта

WEYRIX — это полнофункциональный веб-мессенджер, разработанный с нуля на современном стеке технологий. Проект представляет собой реально работающее приложение для обмена сообщениями в реальном времени с поддержкой личных и групповых чатов, обмена файлами, аватарами пользователей, темами оформления и мультиязычностью.

Проект создавался как учебно-практический с целью изучения асинхронного программирования на Python, работы с WebSocket, JWT-аутентификации, ORM SQLAlchemy и деплоя на облачные платформы. На данный момент Weyrix функционален и готов к использованию как для личного общения, так и для небольших организаций.

Основные характеристики

- Тип приложения: Веб-мессенджер с архитектурой клиент-сервер
- Режим работы: Реальное время (Real-time) с использованием WebSocket
- Масштабируемость: Поддерживает неограниченное количество пользователей и чатов
- Доступность: Круглосуточная работа благодаря облачному хостингу Render
- Кроссплатформенность: Доступен через любой современный браузер


                    Функциональные возможности

Регистрация и авторизация
Система аутентификации построена на JWT-токенах с хранением в HttpOnly cookies, что защищает от XSS-атак. При регистрации каждый пользователь получает уникальный строковый идентификатор в формате Wxxxxxxx (например, Wnkqseugi), который используется для поиска других пользователей.

Процесс регистрации включает проверку уникальности email, валидацию длины пароля (минимум 5 символов, максимум 50), подтверждение пароля. При успешной регистрации автоматически создаётся личный чат "Избранное" с приветственным сообщением от системы. Хэширование паролей выполняется с помощью библиотеки bcrypt перед сохранением в базу данных.

Форма входа принимает email и пароль, проверяет их соответствие хэшу в базе данных и при успехе устанавливает JWT-токен в cookie браузера. Токен действителен 366 дней, после чего пользователю потребуется повторная авторизация.

Управление профилем
Пользователь может редактировать свои данные в личном кабинете:
- Смена имени — новое имя отображается в чатах и в списке пользователей
- Смена email — новый email используется для последующих входов
- Загрузка аватара — поддерживаются изображения в форматах PNG, JPG, JPEG, GIF. Аватар сохраняется на сервере и отображается в профиле
- Просмотр своего ID — уникальный строковый идентификатор для поиска другими пользователями

Личные чаты
Пользователь может начать личный диалог с другим пользователем двумя способами:
1. Поиск по ID — ввод строкового идентификатора в формате Wxxxxxxx в поисковую строку
2. Из профиля пользователя — на странице профиля другого пользователя есть кнопка "Написать сообщение" (Просмотр профиля пользователя через страницу участников группового чата)

После создания чата он появляется в списке чатов на боковой панели. В личном чате доступна кнопка "Удалить чат", которая удаляет все сообщения и сам чат для обоих участников. При этом пользователь, удаливший чат, может позже создать его заново.

Групповые чаты
Групповые чаты позволяют общаться нескольким пользователям одновременно. Функциональность групповых чатов:
- Создание группы — пользователь задаёт название и описание, после чего группа создаётся.
- Просмотр информации о группе — при клике на название группы открывается модальное окно с отображением названия, описания и списка всех участников. Каждый участник в списке кликабелен — при нажатии открывается его профиль
- Приглашение участников — пользователи могут добавлять любого другого пользователя по его строковому ID. Приглашённый участник получает уведомление в чате о присоединении
- Выход из группы — любой участник может покинуть группу. При выходе в чат отправляется системное сообщение. Если после выхода участников не осталось, чат автоматически удаляется со всеми сообщениями

Чат "Избранное"
Это специальный личный чат, который создаётся автоматически для каждого нового пользователя при регистрации. Особенности чата "Избранное":
- Не может быть удалён или покинут
- Служит для хранения личных заметок, напоминаний и ссылок
- Поддерживает отправку текстовых сообщений и файлов
- При первом входе в чат отображается приветственное сообщение от системы.

Обмен сообщениями
Сообщения доставляются в реальном времени через WebSocket-соединение. При отправке сообщения происходит:
1. Оптимистичное обновление интерфейса — сообщение сразу отображается у отправителя
2. Отправка POST-запроса на сервер для сохранения в базе данных
3. Рассылка сообщения всем участникам чата через WebSocket
4. Обновление списка чатов с отображением последнего сообщения

Поддерживаются следующие типы сообщений:
- Текстовые сообщения — обычный текст с поддержкой эмодзи
- Системные сообщения — уведомления о присоединении/выходе участников, выделяются серым фоном и центрируются
- Файловые сообщения — отображаются как ссылка на файл, клик по которой открывает скачивание

Обмен файлами
Пользователи могут отправлять файлы любого типа. Механизм загрузки файлов:
- Файл загружается на сервер через POST-запрос к эндпоинту /chat/upload
- Сервер сохраняет файл с уникальным именем (временная метка + оригинальное имя)
- В чат отправляется системное сообщение с ссылкой на файл
- Ссылка кликабельна и ведёт на скачивание файла
- Поддерживаются любые типы файлов: изображения, документы, архивы, видео

!ВАЖНО: если файл не отображается в чате, попробуйте перезагрузить страницу

Темы оформления
Приложение поддерживает две темы оформления:
- Тёмная тема — тёмно-серые и чёрные тона с зелёными акцентами, неоновое свечение
- Светлая тема — белые и светло-серые тона с фиолетовыми акцентами

Выбранная тема сохраняется в localStorage браузера и применяется при последующих визитах. Переключение происходит мгновенно без перезагрузки страницы.

Мультиязычность
Поддерживаются два языка:
- Русский — полная локализация интерфейса
- Английский — полная локализация интерфейса

Переводы хранятся в JSON-файлах в папке static/i18n/. При смене языка обновляются все текстовые элементы, помеченные атрибутом data-i18n. Выбранный язык сохраняется в localStorage.

Просмотр профилей пользователей
При клике на имя собеседника в шапке чата открывается страница его профиля. На странице профиля отображаются:
- Аватар пользователя
- Уникальный строковый ID
- Имя
- Email
- Кнопка "Написать сообщение" для быстрого начала диалога

Лендинговая страница
Для неавторизованных пользователей отображается лендинговая страница с описанием возможностей мессенджера. На лендинге присутствуют:
- Краткое описание сервиса
- Список ключевых возможностей
- Кнопки перехода к регистрации и входу
- Адаптивный дизайн для всех устройств

!ВАЖНО: если пользователь уже авторизован и пытается зайти на главную страницу, он автоматически перенаправляется в чат.


                        Технологический стек

Языки программирования
- Python 3.12 — основной язык разработки бэкенда. Выбор обусловлен богатой экосистемой асинхронных библиотек и простотой синтаксиса. Используется последняя стабильная версия для доступа к современным возможностям языка.
- JavaScript (ES6+) — язык для фронтенда. Используются современные возможности: async/await для асинхронных операций, стрелочные функции, промисы, Fetch API для HTTP-запросов и WebSocket API для двусторонней связи.
- HTML5 — разметка страниц. Используется семантическая разметка с корректной вложенностью элементов.
- CSS3 — стилизация интерфейса. Используются CSS-переменные для динамической смены тем, Flexbox для построения адаптивных макетов, CSS-анимации для плавных переходов.

                        Backend-фреймворки и библиотеки

FastAPI (0.115.0)
Современный высокопроизводительный веб-фреймворк для Python. Используется как основа приложения. Ключевые особенности, задействованные в проекте:
- Асинхронность — все эндпоинты реализованы как async def для максимальной производительности
- Автоматическая документация — Swagger UI и ReDoc доступны по /docs и /redoc
- Валидация данных — через Pydantic модели
- Dependency Injection — для управления зависимостями (например, get_current_user)
- WebSocket поддержка — встроенная в фреймворк

Uvicorn (0.31.0)
ASGI-сервер для запуска FastAPI-приложения. Используется в production-среде на Render. Настройки:
- Хост: 0.0.0.0 (доступ для всех интерфейсов)
- Порт: 10000 (требование Render)
- Reload режим для разработки

SQLAlchemy (2.0.35)
Мощный ORM для работы с базами данных. Используется асинхронная версия для неблокирующих операций. Компоненты:

- Mapped — типизированные аннотации полей
- async_sessionmaker — фабрика асинхронных сессий

Инструмент для управления миграциями базы данных. Позволяет:
- Автоматически генерировать миграции из изменений моделей
- Применять и откатывать миграции

Pydantic (2.9.2) с email-валидатором
Библиотека для валидации данных и создания схем. Используется:

WebSockets (13.1)
Библиотека для работы с WebSocket на клиенте и сервере. Обеспечивает:

                    Безопасность и шифрование

Аутентификация и авторизация
- JWT токены — используется библиотека python-jose для создания и верификации JSON Web Tokens. Токен подписывается секретным ключом (SECRET_KEY) с использованием алгоритма HS256. Токен содержит идентификатор пользователя и время истечения (366 дней).
- HttpOnly Cookies — токен хранится в cookie с флагом HttpOnly, что защищает от кражи токена через XSS-атаки. JavaScript не имеет доступа к содержимому cookie.
- Защищённые эндпоинты — зависимость get_current_user проверяет валидность токена для всех защищённых маршрутов.

Хэширование паролей
- bcrypt алгоритм — используется библиотека passlib с бэкендом bcrypt. Алгоритм автоматически генерирует соль и выполняет множество раундов хэширования (по умолчанию 12).
- Сравнение паролей — функция verify_password сравнивает введённый пароль с хэшем из базы данных без возможности расшифровки.
- Безопасная генерация соли — bcrypt генерирует случайную соль для каждого пароля, что защищает от радужных таблиц.

Безопасность соединений
- HTTPS — все соединения на Render защищены протоколом HTTPS с автоматическими SSL-сертификатами.
- WSS (WebSocket Secure) — WebSocket соединения используют защищённый протокол wss://, что предотвращает перехват и подмену сообщений.
- CORS настройки — разрешены запросы только с доверенных источников (в разработке разрешены все для удобства).

Защита от уязвимостей
- SQL инъекции — предотвращаются использованием ORM SQLAlchemy, который автоматически экранирует параметры запросов.
- XSS атаки — все пользовательские данные экранируются функцией escapeHtml перед отображением.
- CSRF атаки — защита не реализована, но токен хранится в HttpOnly cookie, что усложняет CSRF.

Безопасность файлов
- Проверка типов — на сервере нет жёсткой проверки типов файлов (можно добавить).
- Уникальные имена — файлы переименовываются при загрузке (временная метка + оригинальное имя), что предотвращает коллизии.
- Доступ по прямой ссылке — файлы доступны по прямой ссылке без дополнительной аутентификации.


                        Базы данных

Используемые СУБД

SQLite (локальная разработка)
- Драйвер: aiosqlite (асинхронный)
- Файл: db.sqlite3
- Преимущества: не требует настройки, легковесная, идеальна для разработки
- Недостатки: не подходит для production (ограничения конкурентности, отсутствие репликации)

PostgreSQL (использование хостинга на Render)
- Драйвер: asyncpg (асинхронный, высокопроизводительный)
- Хостинг: Render PostgreSQL (бесплатный тариф, 1 ГБ хранилища)
- Преимущества: поддерживает конкурентные подключения, надёжное хранение, репликация
- Ограничения бесплатного тарифа: база данных удаляется через 30 дней (если не перейти на платный тариф)

Миграции
Управление миграциями осуществляется через Alembic. Каждая миграция описывает изменения в схеме базы данных. Миграции хранятся в папке app/migration/versions.

Типичные операции миграций:
- Создание новых таблиц
- Добавление/удаление колонок
- Изменение типов колонок
- Создание индексов
- Добавление внешних ключей


Руководство пользователя

Регистрация и первый вход

1. Откройте мессенджер по адресу https://weyrix.onrender.com
2. Нажмите на вкладку "Регистрация"
3. Заполните поля:
   - Email: ваш действующий email
   - Имя: как вас будут видеть другие пользователи
   - Пароль: минимум 5 символов, максимум 50
   - Повторите пароль
4. Нажмите "Зарегистрироваться"
5. После успешной регистрации автоматически переключитесь на вкладку "Вход"
6. Введите email и пароль, нажмите "Войти"
7. После входа вы попадёте в основной интерфейс чата

Навигация по интерфейсу

Боковая панель (слева)
- Верхняя часть: отображается ваше имя и уникальный ID (формат Wxxxxxxx). Здесь же находится меню с тремя точками (⋮), где можно перейти в профиль, настройки или выйти из аккаунта.
- Поисковая строка: поле для ввода ID другого пользователя (формат Wxxxxxxx) и кнопка "Найти" для начала приватного чата.
- Список чатов: отображаются все ваши диалоги. Для каждого чата показано название (имя собеседника или название группы) и последнее сообщение.
- Кнопка "Создать групповой чат": открывает модальное окно для создания группы.

Область чата (справа)
- Верхняя панель: отображает название текущего чата. В групповых чатах название кликабельно и открывает информацию о группе. В приватных чатах имя собеседника кликабельно и ведёт на его профиль. Рядом могут быть кнопки: "Пригласить" (для групповых) или "Удалить чат" (для приватных).
- Область сообщений: показывает историю переписки. Ваши сообщения выровнены по правому краю, сообщения собеседника — по левому. Системные сообщения — по центру.
- Нижняя панель: поле для ввода текста, кнопка отправки и кнопка для прикрепления файлов (📎).

Как начать личный чат с другим пользователем

1. Узнайте уникальный ID собеседника (формат Wxxxxxxx). Он отображается в его профиле и рядом с именем в боковой панели.
2. Введите этот ID в поисковую строку на боковой панели.
3. Нажмите кнопку "Найти".
4. Если пользователь найден, откроется новый приватный чат, и он появится в списке ваших чатов.

Как создать групповой чат

1. Нажмите кнопку "Создать групповой чат" на боковой панели.
2. В появившемся окне введите:
   - Название группы
   - Описание (опционально)
3. Нажмите "Создать".
4. Группа создастсяи и вы будете ее первым участником.
5. Для приглашения участников нажмите на название группы в верхней панели, затем в открывшемся окне нажмите "Пригласить". Введите ID пользователя для приглашения.
6. Приглашённый пользователь получит уведомление о присоединении к чату.

Как работать с чатом "Избранное"

- Чат "Избранное" создаётся автоматически при регистрации.
- Используйте его для личных заметок, напоминаний, сохранения важных ссылок.
- В этот чат можно отправлять текстовые сообщения и файлы.
- Чат "Избранное" нельзя удалить или покинуть.

Как отправлять файлы

1. В нижней панели чата нажмите кнопку с изображением скрепки (📎).
2. Выберите файл в проводнике.
3. Файл автоматически загрузится, и в чат отправится сообщение с ссылкой на скачивание.
4. Другой пользователь может скачать файл, кликнув по ссылке.

Как управлять профилем

1. Нажмите на три точки (⋮) в верхней части боковой панели.
2. Выберите "Аккаунт".
3. На странице профиля вы можете:
   - Нажать на аватар или иконку карандаша ✏️ для загрузки новой аватарки
   - Нажать на блок с именем для его изменения
   - Нажать на блок с email для его изменения
4. Внесите изменения и подтвердите их в появившемся модальном окне.

Как изменить тему и язык

1. Нажмите на три точки (⋮) в верхней части боковой панели.
2. Выберите "Настройки".
3. В открывшемся окне выберите тему (Тёмная/Светлая) и язык (Русский/English).
4. Нажмите "Сохранить". Страница перезагрузится с новыми настройками.

Как посмотреть профиль другого пользователя

1. В приватном чате нажмите на имя собеседника в верхней панели.
2. Откроется страница его профиля с аватаром, именем, ID и email.
3. При желании можно начать диалог, нажав кнопку "Написать сообщение".

Как получить информацию о группе

1. В групповом чате нажмите на название группы в верхней панели.
2. Откроется модальное окно с информацией:
   - Название группы
   - Описание
   - Список всех участников
3. Здесь же можно пригласить новых участников или покинуть группу.

Как покинуть группу или удалить чат

- Групповой чат: нажмите на название группы, затем в модальном окне нажмите "Покинуть чат". Подтвердите действие.
- Личный чат: в верхней панели чата нажмите кнопку "Удалить чат". Чат и все сообщения будут удалены для вас и собеседника.

Как выйти из аккаунта

1. Нажмите на три точки (⋮) в верхней части боковой панели.
2. Выберите "Выйти".
3. Вы будете перенаправлены на страницу входа.


Установка и запуск

Системные требования
- Python 3.12 или выше
- Git
- 2 ГБ свободной оперативной памяти (рекомендуется)
- 500 МБ свободного дискового пространства

Пошаговая установка

1. Клонирование репозитория
   git clone https://github.com/VLAU12/Weyrix.git
   cd Weyrix

2. Создание виртуального окружения
   python -m venv .venv
   source .venv/bin/activate      # Linux/Mac
   .venv\Scripts\activate         # Windows

3. Установка зависимостей
   pip install -r requirements.txt

4. Создание файла .env
   echo SECRET_KEY=your_secret_key_here > .env
   echo ALGORITHM=HS256 >> .env

5. Применение миграций базы данных
   alembic upgrade head

6. Запуск сервера разработки
   uvicorn app.main:app --reload

7. Доступ к приложению
   Откройте браузер и перейдите по адресу http://localhost:8000
